## 📖 About

This repository contains my answers for the **Full Stack Open** course by the University of Helsinki.

The course is an in-depth introduction to modern web application development with JavaScript, focusing on:

* Building Single Page Applications with React
* Creating REST APIs with Node.js and Express
* Using GraphQL as an alternative to REST
* Testing frontend and backend applications
* Managing configuration and environments
* Working with databases
* Production-ready deployment practices

🔗 Official course page:
[https://fullstackopen.com/en/about/](https://fullstackopen.com/en/about/)
